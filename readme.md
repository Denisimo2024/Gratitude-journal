# Gratitude Journal Bot

## Обзор

**Gratitude Journal Bot** — это бот для Telegram, созданный для того, чтобы помочь пользователям практиковать благодарность с помощью голосовых и видео записей. Бот помогает поддерживать осознанность и рефлексию, предоставляя простой и удобный способ фиксировать моменты благодарности каждый день.

### Основные возможности
- **Голосовые и видео записи**: Пользователи могут записывать свои благодарности через голосовые или видео сообщения.
- **Ежедневные напоминания**: Бот отправляет напоминания, чтобы пользователи не забывали вести дневник благодарности.
- **Спокойный дизайн**: Бот имеет простой и приятный интерфейс, вдохновляющий на рефлексию и практику благодарности.
- **Динамический фон**: Фоновое изображение с элементами природы, включая серфингиста на волне, символизирует баланс и гармонию.

### Предварительные требования

Для запуска Gratitude Journal Bot вам потребуется:
- Аккаунт в Telegram
- Python 3.x
- Токен бота Telegram (его можно получить у [BotFather](https://core.telegram.org/bots#botfather))

- [информация о ведения дневника](https://ru.wikipedia.org/wiki/%D0%94%D0%BD%D0%B5%D0%B2%D0%BD%D0%B8%D0%BA)
